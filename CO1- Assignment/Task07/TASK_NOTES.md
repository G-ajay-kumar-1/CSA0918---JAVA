# Task 7 – Report notes

Each concrete vehicle overrides ratePerHour(); Vehicle's calculateFee calls it polymorphically. @Override lets the compiler detect signature mistakes. An override must preserve a compatible signature/return type and cannot reduce access. final can protect registration identity or methods whose rules must not change. equals and hashCode must use the same identity rule; registration number is used here. If a switch on type is used, each added type requires editing the central switch and tests; switch lookup is O(k) in a simple sequential design or O(1) for a well-formed enum switch, but it creates central coupling.
